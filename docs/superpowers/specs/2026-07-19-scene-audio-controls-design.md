# 场景与白噪音控制修复设计

## 范围

四个场景显示名称简化为“雨天、森林、海边、咖啡馆”。森林、海边和咖啡馆暂时沿用现有背景与声音素材。雨天改用用户指定的 Pexels 视频和 Pixabay 音效，并同步素材授权及哈希记录。

## 播放架构

使用单一白噪音控制器统一管理官方录音、自定义音频和程序化 fallback。控制器公开播放、暂停、切换场景、设置音量和停止接口，并保证任意时刻最多一个音源播放。

场景切换立即暂停并复位旧录音，再创建并播放新场景录音，不执行 cross-fade。录音失败时停止失败录音后启动对应程序化 fallback；后续切换场景、恢复官方录音或停止播放时必须关闭 fallback。

播放状态只有 `stopped`、`playing` 和 `paused`。暂停是真正调用音源暂停，不用静音模拟。音量范围为 0–100，直接更新唯一活动音源；音量为 0 时保留 playing 状态。

## 交互

未播放或暂停时按钮显示 `▶`，点击后播放当前场景。播放时显示 `⏸`，点击后暂停。音量滑块不再在 pointer down 时隐式启动音频。

切换场景时，若当前为 playing，停止旧场景并自动播放新场景；若当前为 paused 或 stopped，只更新待播放场景，不自动开始。

## 素材

雨天背景来源为 Hemanth K M 的 Pexels 视频 `5487781`，使用 Pexels License。雨声音效来源为 gingerleegalaxy_1 的 Pixabay 音效 `231100`，使用 Pixabay Content License。下载后转换为项目既有的 `rain.webm`、`rain.webp` 和 `rain.ogg`，并在 `THIRD_PARTY_ASSETS.md` 中记录来源、作者、许可证、处理方法和 SHA-256。

## 测试

测试覆盖场景名称、雨天素材元数据、切换时旧音源先暂停且不交叠、fallback 与录音互斥、真正暂停与恢复、音量即时更新、自定义音频一致行为，以及按钮 `▶/⏸` 与 aria-label。
