Only optimized application assets belong here. Do not commit downloaded source files or editing projects.

- `ambience/`: normalized Ogg Vorbis ambience loops.
- Every file must be recorded in the repository-root `THIRD_PARTY_ASSETS.md` with a source URL, license evidence, modifications, and SHA-256.
